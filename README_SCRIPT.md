# Git提交到Gitee自动化脚本使用说明

## 概述

`commit_to_gitee.sh` 是一个自动化脚本，用于简化Git提交到Gitee仓库的操作流程。该脚本集成了状态检查、文件添加、提交和推送等功能。

## 功能特性

- ✅ 自动检查Git仓库状态
- ✅ 智能添加所有更改文件
- ✅ 支持自定义提交信息
- ✅ 支持指定目标分支
- ✅ 彩色输出，清晰易读
- ✅ 错误处理和安全检查
- ✅ 交互式确认机制

## 使用方法

### 基本用法

```bash
# 使用默认提交信息
./commit_to_gitee.sh

# 指定提交信息
./commit_to_gitee.sh -m "修复算法动画bug"

# 指定分支和提交信息
./commit_to_gitee.sh -b main -m "发布新版本"

# 只查看Git状态，不执行提交
./commit_to_gitee.sh -s
```

### 命令行选项

| 选项 | 长选项 | 说明 |
|------|--------|------|
| `-h` | `--help` | 显示帮助信息 |
| `-s` | `--status` | 只显示Git状态，不执行提交 |
| `-b` | `--branch` | 指定推送的分支名 (默认为当前分支) |
| `-m` | `--message` | 指定提交信息 |

### 使用示例

```bash
# 1. 快速提交当前更改
./commit_to_gitee.sh

# 2. 提交到特定分支
./commit_to_gitee.sh -b feature/new-animation

# 3. 详细的提交信息
./commit_to_gitee.sh -m "feat: 添加新的图算法动画

- 实现Dijkstra算法可视化
- 优化动画性能
- 修复UI显示问题"

# 4. 检查状态后再决定是否提交
./commit_to_gitee.sh -s
./commit_to_gitee.sh -m "确认提交"
```

## 脚本工作流程

1. **环境检查**: 验证是否在Git仓库中，检查Git配置
2. **状态显示**: 展示当前Git状态和待提交文件
3. **用户确认**: 询问是否继续执行提交操作
4. **文件添加**: 自动添加所有更改到暂存区
5. **代码提交**: 使用指定或默认的提交信息提交代码
6. **远程推送**: 推送到指定分支或当前分支

## 安全特性

- 🔒 执行前显示所有待提交的更改
- 🔒 需要用户确认才会执行提交操作
- 🔒 自动检测远程分支是否存在
- 🔒 遇到错误立即停止执行

## 注意事项

1. **首次使用前请确保Git配置正确**:
   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

2. **脚本会添加所有更改文件**，请在执行前检查是否有不需要提交的文件

3. **建议在重要提交前先使用 `-s` 选项查看状态**

4. **脚本支持多行提交信息**，使用引号包围即可

## 故障排除

### 常见问题

**Q: 提示"当前目录不是Git仓库"**
A: 请确保在项目根目录下执行脚本

**Q: 推送失败**
A: 检查网络连接和Gitee仓库权限

**Q: 脚本无法执行**
A: 确保脚本有执行权限：`chmod +x commit_to_gitee.sh`
