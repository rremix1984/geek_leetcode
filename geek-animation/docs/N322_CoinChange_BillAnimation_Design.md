# N322 零钱兑换美元钞票动画设计文档

## 项目概述
为N322零钱兑换算法添加有趣的美元钞票动画效果，展示钞票一张一张数的视觉效果，增强算法学习的趣味性和直观性。

## 功能需求

### 核心功能
1. **钞票动画效果**：展示美元钞票从右上角飞入到堆叠区域的动画
2. **实时计数显示**：显示当前已数钞票数量和总数量
3. **视觉反馈**：钞票移动过程中的高亮效果和缓动动画
4. **结果展示**：最终显示总金额和钞票数量

### 动画特性
- 钞票逐张出现，模拟真实数钞票的过程
- 平滑的移动轨迹和缓动效果
- 钞票堆叠区域的可视化边框
- 移动过程中的光晕特效

### 2. 动画流程设计

#### 动画触发时机
1. **实时动画**：每当dp[i]有解时，显示对应数量的钞票
2. **最终动画**：算法完成时，展示最终结果的钞票动画

#### 动画执行流程
```
1. 检测到有效解 → 启动钞票动画
2. 创建钞票实例 → 设置起始和目标位置
3. 逐张添加钞票 → 每300ms添加一张
4. 钞票移动动画 → 50ms更新一次位置
5. 到达目标位置 → 停止移动，保持显示
```

### 3. 视觉设计

#### 钞票外观设计
- **颜色**：经典美元绿色 (85, 170, 85)
- **尺寸**：60x25像素
- **元素**：美元符号($)、面额(1)、钞票编号
- **特效**：阴影、边框、移动时的光晕效果

#### 布局设计
- **起始位置**：窗口右上角 (width-150, 50)
- **目标区域**：钞票堆叠区 (width-350, 180, 200x150)
- **堆叠方式**：5张一行，错开排列避免重叠

### 4. 性能优化

#### 动画限制
- 最大钞票数量限制为20张，避免性能问题
- 使用Timer控制动画频率，避免过度重绘
- 动画完成后停止Timer，释放资源

#### 内存管理
- 及时清理动画列表
- 停止不必要的Timer
- 重用动画对象

## 用户体验设计

### 1. 交互反馈

## 错误处理

### 边界条件
1. **无解情况**：不显示钞票动画
2. **数量过多**：限制最大20张钞票
3. **窗口大小**：自适应不同窗口尺寸

### 异常处理
1. **Timer异常**：确保Timer正确停止和重启
2. **绘制异常**：添加空值检查
3. **内存泄漏**：及时清理动画资源
