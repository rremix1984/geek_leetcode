# 左侧菜单优化设计文档

## 📋 需求概述

### 功能需求
1. **左侧菜单栏默认折叠**
   - 系统启动时，算法分类树默认为折叠状态
   - 用户可以手动展开需要的分类节点
   - 提供"展开全部"和"折叠全部"的快捷操作

2. **最近访问TOP5算法列表**
   - 在左侧面板顶部添加最近访问的算法列表
   - 显示最近访问的5个算法
   - 支持快速启动最近访问的算法
   - 持久化存储最近访问记录

## 🎯 设计方案

### 1. 菜单折叠功能

#### 1.1 技术实现
- 修改 `expandAllNodes()` 方法，改为 `collapseAllNodes()`
- 添加菜单栏或右键菜单，提供展开/折叠操作
- 保持根节点和主分组节点展开，只折叠具体算法分类

#### 1.2 用户体验优化
- 添加工具栏按钮：展开全部、折叠全部
- 树节点图标区分：展开/折叠状态
- 记住用户的展开偏好

### 2. 最近访问功能

#### 2.1 数据结构设计
```java
public class RecentAlgorithmManager {
    private static final int MAX_RECENT_COUNT = 5;
    private LinkedList<RecentAlgorithmInfo> recentAlgorithms;
    private String configFile = "recent_algorithms.json";
    
    public static class RecentAlgorithmInfo {
        private String algorithmName;
        private String difficulty;
        private String technique;
        private long lastAccessTime;
        private int accessCount;
    }
}
```

#### 2.2 界面布局调整
- 在左侧面板顶部添加"最近访问"区域
- 使用紧凑的列表显示最近访问的算法
- 每个条目显示：算法名称、难度标识、访问时间

#### 2.3 持久化存储
- 使用JSON格式存储最近访问记录
- 文件位置：用户目录/.leetcode_animation/recent_algorithms.json
- 启动时加载，退出时保存
