## 3. 核心功能实现

### 3.1 跳跃游戏动画 (NO055_E_JumpGame_Animation)

#### 3.1.1 算法描述
- **问题**: 给定一个非负整数数组，判断是否能够到达最后一个下标
- **算法**: 贪心算法 + 最远可达位置
- **时间复杂度**: O(n)
- **空间复杂度**: O(1)

#### 3.1.2 动画特性
- 实时显示当前位置和最远可达位置
- 颜色编码：绿色(当前位置)、蓝色(可达区域)、红色(不可达区域)
- 步进式动画演示算法执行过程
- 详细的算法日志输出

#### 3.1.3 核心代码逻辑
```java
// 贪心算法核心逻辑
private boolean canJump(int[] nums) {
    int maxReach = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > maxReach) return false;
        maxReach = Math.max(maxReach, i + nums[i]);
        if (maxReach >= nums.length - 1) return true;
    }
    return false;
}
```

### 3.2 青蛙过河动画 (NO403_H_FrogJump_Animation)

#### 3.2.1 算法描述
- **问题**: 青蛙过河，每次跳跃步数只能是上次步数的k-1、k或k+1
- **算法**: 动态规划 + 状态转移
- **时间复杂度**: O(n²)
- **空间复杂度**: O(n²)

#### 3.2.2 动画特性
- 可视化石头位置和青蛙移动
- 显示每个石头上可能的跳跃步数
- 动态更新DP状态表
- 河流背景和青蛙形象设计

#### 3.2.3 核心代码逻辑
```java
// 动态规划状态转移
Map<Integer, Set<Integer>> dp = new HashMap<>();
for (int step : possibleSteps) {
    for (int nextStep = step - 1; nextStep <= step + 1; nextStep++) {
        if (nextStep > 0) {
            int nextPos = currentPos + nextStep;
            if (stoneIndexMap.containsKey(nextPos)) {
                dp.get(nextPos).add(nextStep);
            }
        }
    }
}
```
