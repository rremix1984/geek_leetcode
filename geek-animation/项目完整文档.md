## 🎯 项目概述

### 项目简介
算法动画系统是一个基于Java Swing的可视化算法学习平台，集成了JVM内存监控功能，帮助开发者更好地理解算法执行过程和JVM内存管理。

### 核心价值
- **可视化学习**: 通过动画展示算法执行过程
- **性能监控**: 实时监控JVM内存使用情况
- **分类管理**: 树形结构管理不同难度的算法
- **开发友好**: 完整的Maven项目结构和文档

## 🔬 技术实现

### JVM内存监控技术

#### G1GC内存显示修正
**问题背景**:
- 传统GC有固定的S0、S1 Survivor区
- G1GC使用动态的"G1 Survivor Space"
- 原显示逻辑不适配G1GC

**解决方案**:
```java
// 修正前：强制显示S0和S1
if (poolName.contains("S0") || poolName.contains("From")) {
    // 更新S0显示
} else if (poolName.contains("S1") || poolName.contains("To")) {
    // 更新S1显示
}

// 修正后：适配G1GC单一Survivor区
if (poolName.contains("Survivor")) {
    // 统一更新Survivor区显示
    updateSurvivorDisplay(used, max);
}
```

#### 内存池识别逻辑
```java
// 实际的G1GC内存池名称
"G1 Eden Space"      → Eden区
"G1 Survivor Space"  → Survivor区  
"G1 Old Gen"         → 老年代
```

### CodeCache优化解决方案

**问题**: CodeCache满导致编译器禁用
```
CodeCache: size=245760Kb used=75431Kb max_used=75431Kb free=170328Kb
```

**解决方案**:
```bash
# JVM参数优化
-XX:ReservedCodeCacheSize=512m
-XX:InitialCodeCacheSize=64m
-XX:CodeCacheExpansionSize=32m
```

## 📖 使用指南

### 统一管理脚本 (推荐)
项目提供了 `all_in_one.sh` 统一管理脚本，整合了所有功能：

```bash
# 查看帮助
./all_in_one.sh help

# 启动所有服务
./all_in_one.sh start

# 只启动算法动画程序
./all_in_one.sh start --animation

# 使用优化参数启动
./all_in_one.sh start --optimized

# 后台启动所有服务
./all_in_one.sh start --background

# 查看系统状态
./all_in_one.sh status

# 停止所有服务
./all_in_one.sh stop

# 重启服务
./all_in_one.sh restart

# 查看日志
./all_in_one.sh logs --animation --follow

# 验证JMX连接
./all_in_one.sh verify

# 编译项目
./all_in_one.sh compile

# 清理日志
./all_in_one.sh clean
```

### 快速启动流程
1. **启动服务**：
   ```bash
   ./all_in_one.sh start
   ```

2. **连接JMX监控**：
   - 在监控工具界面选择"手动输入JMX端口"
   - 输入端口号：9999
   - 点击连接开始监控

3. **查看状态**：
   ```bash
   ./all_in_one.sh status
   ```

### 常用操作
- **实时查看算法程序日志**：`./all_in_one.sh logs --animation --follow`
- **只启动内存监控**：`./all_in_one.sh start --memory`
- **验证JMX连接**：`./all_in_one.sh verify`
- **停止特定服务**：`./all_in_one.sh stop --animation`

### 算法动画使用
1. 运行 `AlgorithmTreeLauncher`
2. 在树形界面中选择算法分类
3. 选择具体算法并启动动画
4. 使用控制按钮操作动画播放

## 🔧 问题解决

### 常见问题及解决方案

#### 1. JMX连接失败
**问题**: 监控工具无法连接到算法程序
**解决**:
```bash
# 检查端口占用
lsof -i :9999

# 验证JMX配置
./verify_jmx_port.sh

# 重启服务
./stop_all.sh && ./quick_start.sh
```

#### 2. 内存显示异常
**问题**: Survivor区显示为空或错误
**解决**: 已通过G1GC适配修正，确保使用最新版本

#### 3. CodeCache警告
**问题**: 编译器被禁用
**解决**: 使用优化启动脚本 `start_final_optimized.sh`

#### 4. 字体缺失警告
**问题**: 监控工具字体渲染警告
**影响**: 不影响功能，仅影响显示效果
**解决**: 可忽略或安装相应字体

## 🚀 部署说明

### 环境要求
- **JDK**: 8+ (推荐JDK 11)
- **Maven**: 3.6+
- **操作系统**: macOS/Linux/Windows
- **内存**: 建议4GB+

### 编译部署
```bash
# 编译项目
mvn clean compile

# 运行测试
mvn test

# 打包项目
mvn package

# 启动服务
./quick_start.sh
```

### 配置说明
```bash
# JVM参数配置
-Xms512m -Xmx2g
-XX:+UseG1GC
-XX:ReservedCodeCacheSize=512m
-Dcom.sun.management.jmxremote.port=9999
-Dcom.sun.management.jmxremote.authenticate=false
-Dcom.sun.management.jmxremote.ssl=false
```
