# JVM内存监控工具使用说明

## 工具概述

这是一个基于Swing开发的JVM内存实时监控工具，专门用于监控Java虚拟机的内存使用情况，特别关注CodeCache的使用状态。

## 功能特性

### 🎯 核心监控功能
1. **实时内存监控**：每秒自动刷新内存使用数据
2. **CodeCache重点监控**：特别突出显示CodeCache使用情况
3. **多维度内存分析**：覆盖堆内存、非堆内存、元空间等
4. **可视化展示**：使用进度条和颜色编码直观显示
5. **系统信息监控**：CPU使用率、线程数、运行时间等

### 📊 监控内容详解

#### 1. 系统信息面板
- **运行时间**：JVM启动后的运行时长
- **活跃线程**：当前活跃的线程数量
- **CPU使用率**：进程CPU占用百分比
- **系统内存**：物理内存使用情况

#### 2. 堆内存监控 (Heap Memory)
- **已使用**：当前堆内存使用量
- **最大值**：堆内存最大限制
- **使用率进度条**：可视化显示使用百分比
- **颜色警告**：
  - 🟢 绿色：使用率 < 60%
  - 🟠 橙色：使用率 60-80%
  - 🔴 红色：使用率 > 80%

#### 3. 非堆内存监控 (Non-Heap Memory)
- 包含方法区、代码缓存、压缩类空间等
- 实时显示使用量和最大限制

#### 4. 🔥 CodeCache重点监控
- **特殊标识**：浅黄色背景突出显示
- **详细信息**：已使用、最大值、使用率
- **实时警告**：
  - 🟠 橙色：使用率 > 70%
  - 🔴 红色：使用率 > 90% (显示⚠️警告)
- **橙色进度条**：专门的颜色标识

#### 5. 元空间监控 (Metaspace)
- 类元数据存储区域
- 动态扩展，通常无固定上限

#### 6. 压缩类空间 (Compressed Class Space)
- 启用压缩指针时的类指针存储区域
- 固定大小限制

#### 7. 垃圾回收信息
- **GC次数**：累计垃圾回收次数
- **GC时间**：累计垃圾回收耗时

## 使用方法

### 启动工具
```bash
# 方法1：使用启动脚本（推荐）
./start_memory_monitor.sh

# 方法2：直接运行Java命令
java -cp target/classes com.leetcode.tools.JVMMemoryMonitor
```

### 界面操作
1. **自动刷新**：工具每秒自动更新数据
2. **立即刷新**：点击"立即刷新"按钮手动更新
3. **执行GC**：点击"执行GC"按钮触发垃圾回收
4. **退出程序**：点击"退出"按钮关闭工具

## 实际应用场景

### 1. CodeCache问题诊断
当遇到以下警告时，可以使用此工具监控：
```
OpenJDK 64-Bit Server VM warning: CodeCache is full. Compiler has been disabled.
```

**监控要点**：
- 观察CodeCache使用率变化
- 确认是否达到最大限制
- 监控编译器禁用状态

### 2. 内存泄漏检测
- 长时间运行观察内存增长趋势
- 关注堆内存使用率是否持续上升
- 监控GC频率和效果

### 3. 性能优化
- 评估JVM参数设置效果
- 观察不同负载下的内存使用模式
- 优化内存分配策略

### 4. 生产环境监控
- 实时监控关键应用的内存状态
- 预警内存使用异常
- 辅助故障排查

## 技术实现

### 核心技术栈
- **UI框架**：Java Swing
- **监控API**：Java Management Extensions (JMX)
- **内存管理**：MemoryMXBean, MemoryPoolMXBean
- **系统监控**：OperatingSystemMXBean
- **垃圾回收**：GarbageCollectorMXBean

### 关键特性
- **实时更新**：Timer定时器每秒刷新
- **异常处理**：完善的错误处理机制
- **跨平台**：支持Windows、macOS、Linux
- **低开销**：监控工具本身资源占用极小

## 配置说明

### JVM参数优化
启动脚本中的关键参数：
```bash
-Xmx1g                    # 最大堆内存1GB
-Xms256m                  # 初始堆内存256MB
-XX:+UseG1GC              # 使用G1垃圾收集器
-XX:MaxGCPauseMillis=200  # 最大GC停顿时间
```

### 系统要求
- **Java版本**：Java 8或更高版本
- **内存要求**：至少512MB可用内存
- **显示要求**：支持图形界面的操作系统

## 故障排除

### 常见问题

#### 1. 字体警告
```
Warning: the fonts "Times" and "Lucida Bright" are not available
```
**解决方案**：这是正常的字体警告，不影响功能使用。

#### 2. CodeCache满载
```
CodeCache is full. Compiler has been disabled.
```
**解决方案**：
- 增加CodeCache大小：`-XX:ReservedCodeCacheSize=256m`
- 启用CodeCache清理：`-XX:+UseCodeCacheFlushing`

#### 3. 权限问题
**解决方案**：确保启动脚本有执行权限
```bash
chmod +x start_memory_monitor.sh
```
