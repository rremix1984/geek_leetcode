### 核心算法
```java
// 快慢指针 + 栈方法
public boolean isPalindrome(ListNode head) {
    ListNode fast = head, slow = head;
    Stack<Integer> stack = new Stack<>();
    
    // 第一阶段：找到中点，压栈前半部分
    while (fast != null) {
        if (fast.next != null) {
            fast = fast.next.next;
            stack.push(slow.val);
        } else {
            fast = fast.next; // 奇数个节点
        }
        slow = slow.next;
    }
    
    // 第二阶段：比较栈与后半部分
    while (slow != null) {
        if (stack.peek() != slow.val)
            return false;
        stack.pop();
        slow = slow.next;
    }
    return true;
}
```
