# 启动脚本系统设计文档

## 1. 系统概述

本系统提供了一套完整的脚本解决方案，用于同时启动算法动画程序和JVM监控工具，实现一键启动、自动配置和便捷管理。

## 2. 系统架构

### 2.1 核心组件

```
启动脚本系统
├── quick_start.sh                    # 快速启动脚本（推荐）
├── start_animation_with_monitor.sh   # 完整功能启动脚本
├── start_algorithm_with_jmx.sh       # 单独启动算法程序
├── start_process_monitor.sh          # 单独启动监控工具
├── stop_all.sh                       # 停止所有程序
└── 启动脚本使用说明.md               # 详细使用说明
```

### 2.2 程序组件

- **算法动画程序**: `AlgorithmTreeLauncher` - 提供算法可视化界面
- **JVM监控工具**: `JVMProcessMonitor` - 提供实时JVM性能监控

## 3. 技术特性

### 3.1 自动化功能

1. **环境检查**
   - Java版本验证（要求Java 8+）
   - JMX端口可用性检查（默认9999）
   - 项目编译状态检查

2. **智能编译**
   - 自动检测是否需要重新编译
   - 增量编译支持
   - 编译错误处理

3. **进程管理**
   - 自动清理冲突进程
   - PID跟踪和管理
   - 优雅停止机制

### 3.2 JVM优化配置

#### 算法动画程序配置
```bash
-Xms2g -Xmx6g                          # 堆内存：2GB-6GB
-XX:ReservedCodeCacheSize=2048m        # CodeCache：2GB
-XX:+UseG1GC                           # G1垃圾收集器
-Dcom.sun.management.jmxremote.port=9999  # JMX远程监控
```

#### JVM监控工具配置
```bash
-Xms512m -Xmx1g                        # 堆内存：512MB-1GB
-XX:+UseG1GC                           # G1垃圾收集器
```

### 3.3 日志管理

- **日志目录**: `logs/`
- **算法程序日志**: `logs/animation.log`
- **监控工具日志**: `logs/monitor.log`
- **实时日志查看**: `tail -f logs/*.log`

## 5. 使用流程

### 5.1 快速启动流程

```bash
# 1. 启动程序
./quick_start.sh

# 2. 连接监控
# - 在监控工具界面选择"手动输入JMX端口"
# - 输入端口号: 9999
# - 点击连接

# 3. 停止程序
./stop_all.sh
```

### 5.2 监控连接步骤

1. **启动程序**: 运行启动脚本
2. **等待就绪**: 等待JMX服务启动（约3-5秒）
3. **打开监控**: JVM监控工具自动启动
4. **手动连接**: 选择"手动输入JMX端口"
5. **输入端口**: 输入9999
6. **开始监控**: 点击连接按钮

## 6. 故障排除

### 6.1 常见问题

1. **端口冲突**
   ```bash
   # 检查端口占用
   lsof -i :9999
   
   # 释放端口
   ./stop_all.sh
   ```

2. **编译失败**
   ```bash
   # 手动编译
   mvn clean compile
   
   # 检查Java版本
   java -version
   ```

3. **JMX连接失败**
   ```bash
   # 检查程序状态
   ps aux | grep AlgorithmTreeLauncher
   
   # 检查JMX端口
   netstat -an | grep 9999
   ```

### 6.2 性能优化

1. **内存不足**
   - 调整堆内存大小：修改`-Xmx`参数
   - 监控内存使用：使用JVM监控工具

2. **CodeCache满**
   - 增加CodeCache大小：修改`-XX:ReservedCodeCacheSize`
   - 当前配置已优化至2GB

## 7. 系统要求

### 7.1 硬件要求

- **内存**: 最少4GB，推荐8GB+
- **CPU**: 双核以上
- **磁盘**: 至少1GB可用空间

### 7.2 软件要求

- **操作系统**: macOS/Linux/Windows
- **Java**: JDK 8或更高版本
- **Maven**: 3.6+（用于编译）

## 8. 安全考虑

### 8.1 JMX安全

- 当前配置为本地开发环境，未启用认证
- 生产环境建议启用SSL和认证
- JMX端口仅绑定localhost

### 8.2 进程安全

- 脚本包含进程清理机制
- 避免僵尸进程产生
- 优雅停止避免数据丢失

## 10. 维护指南

### 10.1 日常维护

1. **定期清理日志**
   ```bash
   # 清理旧日志
   rm -f logs/*.log.old
   ```

2. **监控资源使用**
   - 使用JVM监控工具观察内存使用
   - 关注GC频率和耗时

3. **更新依赖**
   ```bash
   # 更新Maven依赖
   mvn clean compile
   ```

### 10.2 故障恢复

1. **程序崩溃恢复**
   ```bash
   # 停止所有程序
   ./stop_all.sh
   
   # 重新启动
   ./quick_start.sh
   ```

2. **配置恢复**
   - 检查脚本权限：`chmod +x *.sh`
   - 验证Java环境：`java -version`

## 12. 技术支持

如遇到问题，请按以下顺序排查：

1. 查看日志文件：`logs/animation.log` 和 `logs/monitor.log`
2. 检查进程状态：`ps aux | grep -E "(AlgorithmTreeLauncher|JVMProcessMonitor)"`
3. 验证端口状态：`lsof -i :9999`
4. 重新编译项目：`mvn clean compile`
5. 完全重启：`./stop_all.sh && ./quick_start.sh`
