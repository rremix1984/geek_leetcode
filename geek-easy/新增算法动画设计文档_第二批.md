## 新增算法列表

### 1. NO.026 删除有序数组中的重复项 (Remove Duplicates from Sorted Array)

**文件位置**: `src/main/java/com/leetcode/animation/NO026_E_RemoveDuplicatesFromSortedArray_Animation.java`

**算法分类**: 数组算法
**难度**: Easy
**核心技术**: 双指针 + 原地删除

**问题描述**:
给你一个升序排列的数组nums，请你原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。

**算法思路**:
- 使用双指针技术，slow和fast指针
- fast指针遍历整个数组
- 当nums[fast] != nums[slow]时，将nums[fast]复制到nums[slow+1]
- slow指针向前移动，继续处理下一个不重复元素

**动画特色**:
- 可视化双指针的移动过程
- 高亮显示重复和非重复元素
- 实时显示数组的变化
- 支持自定义数组输入

### 2. NO.121 买卖股票的最佳时机 (Best Time to Buy and Sell Stock)

**文件位置**: `src/main/java/com/leetcode/animation/NO121_E_BestTimeToBuyAndSellStock_Animation.java`

**算法分类**: 贪心算法
**难度**: Easy
**核心技术**: 贪心 + 一次遍历

**问题描述**:
给定一个数组prices，它的第i个元素prices[i]表示一支给定股票第i天的价格。你只能选择某一天买入这只股票，并选择在未来的某一天卖出该股票。设计一个算法来计算你所能获取的最大利润。

**算法思路**:
- 维护一个最小价格minPrice
- 遍历价格数组，更新最小价格
- 计算当前价格与最小价格的差值（利润）
- 维护最大利润maxProfit

**动画特色**:
- 可视化股票价格走势图
- 高亮显示最佳买入和卖出时机
- 实时显示当前最大利润
- 支持自定义价格数据

### 3. NO.136 只出现一次的数字 (Single Number)

**文件位置**: `src/main/java/com/leetcode/animation/NO136_E_SingleNumber_Animation.java`

**算法分类**: 位运算
**难度**: Easy
**核心技术**: 位运算 + 异或性质

**问题描述**:
给定一个非空整数数组，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

**算法思路**:
- 利用异或运算的性质：a ⊕ a = 0，a ⊕ 0 = a
- 相同的数字异或结果为0
- 任何数字与0异或都等于它本身
- 遍历数组，将所有数字进行异或运算

**动画特色**:
- 可视化异或运算过程
- 显示二进制位的变化
- 高亮显示相同数字的抵消过程
- 支持自定义数组输入

### 4. NO.283 移动零 (Move Zeroes)

**文件位置**: `src/main/java/com/leetcode/animation/NO283_E_MoveZeroes_Animation.java`

**算法分类**: 数组算法
**难度**: Easy
**核心技术**: 双指针 + 原地移动

**问题描述**:
给定一个数组nums，编写一个函数将所有0移动到数组的末尾，同时保持非零元素的相对顺序。

**算法思路**:
- 使用双指针技术，left指向下一个非零元素的位置
- right指针遍历整个数组
- 当nums[right] != 0时，交换nums[left]和nums[right]
- left指针向前移动

**动画特色**:
- 可视化双指针的移动过程
- 高亮显示零和非零元素
- 实时显示元素交换过程
- 支持自定义数组输入
