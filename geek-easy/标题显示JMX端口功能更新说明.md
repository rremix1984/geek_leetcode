# 标题显示JMX端口功能更新说明

## 1. 功能概述

为了提高用户体验和便于监控连接，我们在算法动画演示系统的窗口标题中添加了JMX端口号显示功能。

## 2. 功能特性

### 2.1 智能端口检测

- **自动检测**: 系统自动检测JMX远程监控端口配置
- **动态显示**: 根据JMX端口状态动态调整标题内容
- **用户友好**: 清晰显示当前可用的监控端口

### 2.2 标题格式

#### 启用JMX监控时
```
LeetCode算法动画演示系统 - 树形分类版 [JMX端口: 9999]
```

#### 未启用JMX监控时
```
LeetCode算法动画演示系统 - 树形分类版
```

## 3. 技术实现

### 3.1 核心代码

```java
private AlgorithmTreeLauncher() {
    // 获取JMX端口号并设置标题
    String jmxPort = System.getProperty("com.sun.management.jmxremote.port", "未启用");
    String title = "LeetCode算法动画演示系统 - 树形分类版";
    if (!"未启用".equals(jmxPort)) {
        title += " [JMX端口: " + jmxPort + "]";
    }
    setTitle(title);
    // ... 其他初始化代码
}
```

### 3.2 实现原理

1. **系统属性读取**: 通过 `System.getProperty()` 读取JMX端口配置
2. **条件判断**: 检查端口是否已配置
3. **动态标题**: 根据端口状态构建相应的窗口标题

### 7.2 手动配置JMX

如需手动配置JMX端口：

```bash
java -Dcom.sun.management.jmxremote.port=9999 \
     -Dcom.sun.management.jmxremote.authenticate=false \
     -Dcom.sun.management.jmxremote.ssl=false \
     -cp target/classes com.leetcode.animation.AlgorithmTreeLauncher
```

## 8. 故障排除

### 8.1 端口不显示

**问题**: 标题中没有显示JMX端口号

**解决方案**:
1. 检查JMX配置参数是否正确
2. 确认系统属性设置是否生效
3. 重新启动程序

### 8.2 端口显示错误

**问题**: 显示的端口号与实际不符

**解决方案**:
1. 检查启动脚本中的端口配置
2. 确认没有端口冲突
3. 验证JMX服务是否正常启动
